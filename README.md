# BilSec Guardian

## Kurulum ve Çalıştırma

Gereksinim: Node.js 18+.

```bash
npm install
npm run dev
```

Ardından Vite'in terminalde bildirdiği yerel adresi tarayıcıda açın.

## Yapay Zekâ Yapılandırması (opsiyonel)

Canlı yapay zekâ özellikleri için `.env.example` dosyasını `.env` olarak kopyalayıp `AI_API_KEY`, `AI_API_URL` ve `AI_MODEL` değerlerini girin. Yapılandırma yoksa uygulama gömülü örnek (fallback) çıktılarla çalışır.
